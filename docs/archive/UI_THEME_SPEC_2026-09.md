# Codex 任务：辰南撰写项目三套 UI 全量实现 + 可切换主题

## 目标
基于已确认的三套视觉方向，全部实现，不做三选一。三套主题必须在同一套真实业务功能上运行，并可即时切换：

1. **水墨雅致风**（theme id: `ink`）
2. **现代简约白灰风**（theme id: `modern`）
3. **深色专业金黑风**（theme id: `dark`）

这是 **Growth Story Workspace / 辰南撰写项目** 的 UI 重构任务，不是交易平台 UI。不得引入股票行情、资产卡片、订单等交易系统元素。

## 不允许改坏的现有业务
保留当前真实功能、数据与路由逻辑，只重构视觉与布局。人物、每日撰写、专业文档、人物记忆/关联、素材、统计/设置等现有模块继续使用现有数据源和操作逻辑，禁止以静态 mock 替换真实功能。

## 主题系统
建立统一 design-token 层，不复制三套页面代码。

建议：
- 根节点：`<html data-theme="ink|modern|dark">`
- CSS Variables / Tailwind tokens / ThemeProvider 统一驱动颜色、阴影、边框、背景、字体、纹理、图标状态与动效。
- 主题状态集中管理，例如 `ThemeProvider` + `useTheme()`。
- 切换主题后无需刷新页面。
- `localStorage` 持久化用户选择；刷新、重新登录后保持上次主题。
- 首次进入默认 `ink`。
- QA 辅助：支持 `?theme=ink|modern|dark`（如不影响现有路由）。
- 不得为每个主题复制一整套业务组件。

## 主题一：水墨雅致风
视觉关键词：
- 宣纸白、暖灰、淡墨、少量朱砂红/古铜金。
- 山水留白、轻雾、毛笔墨迹、印章细节。
- 主界面干净，不让装饰压过正文编辑区。
- 卡片半透明但保持高可读性。

### 毛笔书写特效（必须真实实现）
“辰南”Logo / 标题入场必须具有 **毛笔逐笔书写动画**：
- 优先 SVG path + `stroke-dasharray / stroke-dashoffset`，或 mask/path reveal。
- 笔锋出现粗细、飞白、收笔墨迹扩散感。
- 完成后淡入印章。
- 目标时长约 1.4–2.2 秒。
- 登录页首次加载明显，主工作台 Logo 只做轻量短动画，避免干扰编辑。
- `prefers-reduced-motion: reduce` 时自动切成静态 Logo / 简单淡入。
- 禁止用超大视频/GIF冒充效果。

## 主题二：现代简约白灰风
视觉关键词：
- 高级白灰、轻冷色玻璃感、低饱和蓝作为交互强调。
- 大面积留白，信息层级清楚。
- 窄边框、柔和阴影、8/12/16px 统一圆角体系。
- 强调效率和可读性，正文区域最大化。
- Logo 保留毛笔品牌感，但整体界面更现代、轻量。

## 主题三：深色专业金黑风
视觉关键词：
- 墨黑 / 深蓝黑背景，香槟金 / 古铜金作为品牌强调。
- 禁止廉价纯黑+亮黄；用低饱和层次、柔和边框和微光。
- 编辑区必须长时间阅读舒适。
- 山水夜景只用于登录页、空白区或弱背景层，不影响正文对比度。
- Logo 使用金色毛笔书写特效。

## 登录页面
三套主题都必须拥有对应的完整登录视觉，不是只改背景色。

要求：
- 桌面端 16:9 构图。
- 移动端单独响应式构图，不把桌面画面简单缩小。
- 辰南 Logo + “笔尖上的比特币”品牌文字。
- 登录卡片、按钮、输入状态、错误提示、loading、记住登录等按现有认证逻辑接入。
- 登录页提供主题切换入口，登录后继承该主题。
- 毛笔书写动效在登录页最完整。
- 不更改现有认证 API / session 逻辑。

## 桌面工作台布局
目标为高密度专业写作工作台：
- 16:9 屏幕优先设计；常见 1366×768、1440×810、1920×1080 都需正常。
- 主体尽量一屏完成核心操作，避免无意义纵向滚动。
- 左侧主导航可折叠。
- 人物列表列尽量窄，按当前项目既有排序/筛选规则展示。
- 中间正文编辑区占最大面积。
- 右侧为人物信息、记忆、关联记录等上下文面板，可折叠。
- “每日撰写内容”独立保存逻辑必须保持。
- 搜索、保存状态、导出、日期/人物选择等真实功能不丢失。

## 手机端
必须是真正的移动端布局：
- 375 / 390 / 414 / 430 px 宽度重点测试。
- 不出现横向滚动。
- 底部导航或抽屉导航按信息优先级重排。
- 人物列表、撰写编辑、人物详情分别适配为独立移动页面/层级，不强行三栏缩放。
- 编辑器工具栏支持横向滚动/折叠，不遮挡正文。
- 主题切换在手机端同样可用并持久化。
- 深色主题遵守 safe-area / iPhone 刘海与底部 Home Indicator。

## 动效规范
动效必须克制、可关闭：
- 页面入场：150–300ms。
- 卡片/导航 hover：120–180ms。
- 面板切换：180–260ms。
- 毛笔 Logo：1.4–2.2s。
- 不允许所有元素同时漂浮、闪烁或大幅位移。
- `prefers-reduced-motion` 全局支持。

## 推荐组件结构
可按当前技术栈调整，但职责应类似：
- `ThemeProvider`
- `ThemeSwitcher`
- `BrandBrushLogo`
- `AppShell`
- `PrimarySidebar`
- `CharacterListPanel`
- `WritingEditorPanel`
- `CharacterContextPanel`
- `MobileBottomNav`
- `LoginShell`

主题差异放入 tokens / variants，不复制业务逻辑。

## 验收标准
以下全部通过才算完成：

1. 三套主题可即时切换，切换不刷新页面。
2. 刷新页面与重新进入后保留主题选择。
3. 登录页三套视觉均完整实现，并能在登录前切换。
4. 登录后沿用登录页选中的主题。
5. 桌面端核心工作台三套主题均实现。
6. 手机端三套主题均实现，不是桌面端缩放版。
7. “辰南”毛笔 Logo 有真实逐笔书写/墨迹动画，并支持 reduced motion。
8. 人物、每日撰写、文档、人物记忆/关联、素材、统计等现有真实功能无回归。
9. 不引入 mock 数据替换现有真实数据。
10. 1366×768 / 1440×810 / 1920×1080 无明显溢出、遮挡。
11. 375 / 390 / 414 / 430 宽度无横向溢出和不可点击控件。
12. Chrome / Safari 移动端基础兼容。
13. TypeScript / lint / build 通过。
14. 对主题切换、持久化、关键响应式布局补必要测试。
15. 完成后提供变更文件清单、测试结果、剩余问题（如有），不要把未验证项写成“已完成”。

## 实现优先级
P0：主题基础架构、登录页、主工作台、移动端、毛笔 Logo 动效。
P1：人物详情/记忆/专业文档/素材/统计等所有内部页面全面主题化。
P2：微交互、空状态、loading、错误态、视觉细节统一。

本任务对应用户已经确认的三套视觉稿：
