# 辰南统一 UI 设计系统 · 最终实施规范

更新：2026-10-03  
母版：投资者人物总览 + 人物库

## 1. 唯一视觉母版
后续所有一级页面、动态页面、详情页、编辑弹窗、表格、空状态均继承“概览 / 人物库”的高级白灰金融工作台视觉。禁止另起深色主题、背景图、另一套导航、另一套框线或字体。

## 4. 统一交互
- 一级大模块和详情大模块：不整体浮起。
- 仅人物行、交易行、候选人物、持仓人物、文档项、记录项、小组单个人物条目允许 1px 轻微 hover。
- ESC：弹窗优先关闭；二级页面返回所属一级页面；持仓管理可回人物交易。
- 动态二级页保持所属一级导航高亮。

## 5. 表格
- 表头统一浅灰、纯黑文字。
- 1px 浅灰边线。
- 行高一致，数值和状态清晰。
- 操作链接：普通深蓝，删除深红。
- 人物库使用分页，不无限向下滚动。

## 6. 空状态
统一为：图标 + “暂无内容” + 当前真实空状态说明。不得只留一句悬空灰字。

## 7. 技术落地
- design-system.css：最终视觉覆盖层与 tokens。
- design-system.js：动态页面归一化、图标、Header、表格、空状态、弹窗、二级导航与 ESC。
- 原业务脚本保留，不重写数据结构。
- 旧样式仍可存在，但最终由 design-system.css 最后加载覆盖。

## 8. 验收原则
任何新增页面必须：
- 使用相同 sidebar
- 使用相同 Header
- 使用相同边框 / 圆角 / 字体 / 控件
- 不新增背景图
- 不新增独立主题
- 不在父模块 hover 时整体漂浮
- 二级页面必须保持父级导航关系
