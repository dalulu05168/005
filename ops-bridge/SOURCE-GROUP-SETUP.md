# Nuvexa Pro：连接来源群（管理员账号授权）

## 当前能力

此功能在 Cloud Edition 后台左侧 **来源群** 页面中配置。使用 Telegram MTProto **用户账号**登录，不需要创建 Telegram Bot，不需要 DeepL 或任何翻译密钥。

授权采用 Telegram 官方 API ID + API Hash 和账号手机号码。验证码、两步验证密码必须在后台的安全登录表单输入，**不要发到聊天里**。程序把 Telegram Session、API Hash、关联群组状态用 AES-256-GCM 加密存入服务现有 Redis；浏览器仅显示手机号后四位和连接状态。用户可以随时“暂停采集”或“断开并撤销采集会话”。

## 连接顺序

1. 登录 <https://admin.nuvexapro.com>，左侧进入 **来源群**。
2. 如果没有 Telegram 开发者凭据，在官方 <https://my.telegram.org/apps> 获取 API ID / API Hash；两者均为保密凭据，不要提交到 GitHub、邮件或聊天。
3. 在页面填写 API ID、API Hash、包含国际区号的管理员 Telegram 手机号码，点击 **发送 Telegram 验证码**。
4. Telegram 会向你的应用（有时为手机）发送验证码，**在页面输入**。如开启两步验证，输入账号的两步验证密码。不要请求他人提供验证码。
5. 授权完成后点击 **读取可访问群组列表**，从列表选中截图中的“罗马尼亚剧本群（万国团队）”，点击 **仅保存来源群**。
6. 在账号管理连接真实 WhatsApp 发送账号、群组设置配置获授权的目标 WhatsApp 群组后，才可以点击 **启用该群采集**。缺少发送账号或目标群组时后台会阻止启用，不会使用虚拟账号。
7. 发送端还需要真实 WhatsApp Worker；现有服务中的`ACKED`模拟回执**不能**等同于实际消息送达，必须通过授权测试群端到端验证。
8. 如果只是暂时停用，点击“暂停采集”；彻底断开，点击“断开并撤销当前采集会话”。

## 从消息中提取什么

- 来源群需包含“资讯助理”、“教授”或“45男”、“2女”等支持的角色标识。
- 每条消息中：**上面中文原文、下面已有译文**。系统仅提取最后一条中文原文之后的非中文文本；可保留原有英文。没有译文就阻止文字转发，绝不自动翻译。
- 当来源消息**本身附带图片**时，按 MTProto 原始消息 ID 留存图片引用（`tgmsg:<chat-id>:<message-id>`），图片内容不做 OCR、视觉识别或改写。发送端需要通过受 Agent Key 保护的 `/v1/worker/media` API 下载原始图片字节。
- 图片和文字是独立任务；图片不使用、不重置文字发送间隔。
- 只监听你在后台**明确选择并启用**的一个来源群；其他群和未识别的角色消息不会采集。
- 图片只有在与来源角色文本能安全关联时才可进入发送任务；无法归属时保留待处理或拒绝。
- 这是后台服务主动保持的 Telegram 长连接。**Render 免费 Web Service 可能休眠**；若要求不间断实时采集，需使用支持持续运行的实例或受控本地常驻服务。服务重启后可从已加密保存的会话恢复，但停机期间错过的消息当前**不会自动补采**，不能声称 24 小时不丢消息。

## 保护原则

- API Hash、Session、两步验证密码、验证码不会在服务日志、状态接口或页面中回显。
- 只有管理员登录 Bearer Token 才可调用 `/v1/source/*` 授权管理 API。
- 来源采集默认关闭，只有成功账号授权、选群以及具有启用的 WhatsApp 群和在线账号，才允许启用。
- 未运行真实 Telegram 登录或 WhatsApp 发送实测之前，任何“测试通过”仅代表隔离模拟、接口连接与代码测试结果。
